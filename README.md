# CloudFinOps AI

AI-assisted FinOps platform for AWS and Azure. Investigates cost changes, detects waste, forecasts spend, and generates evidence-backed optimization recommendations with human approval.

## Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS, Recharts
- Backend: FastAPI (planned, currently mocked)
- Data: PostgreSQL, Redis, Parquet, DuckDB

## Getting started

```bash
npm install
npm run dev
